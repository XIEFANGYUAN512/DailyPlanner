# DailyPlanner

DailyPlanner 是一个用于记录每日安排的轻量前端网页。它不依赖后端服务，打开网页即可添加、查看和管理当天日程，适合个人日计划、学习安排、生活事项和简单任务记录。

## 功能

- 添加日程：支持选择日期、时间、日程内容和类型。
- 按日期查看：可以切换不同日期查看对应日程。
- 完成状态：每条日程可以标记完成或取消完成。
- 可编辑备注：每条日程下方都有独立备注框，任务完成后仍然可以查看和编辑。
- 关键词搜索：支持按日程内容、备注、类型、日期和时间搜索。
- 日历视图：以月历形式查看每天的日程数量和完成情况，点击日期即可切换到当天列表。
- 导入和导出：支持将日程导出为 JSON 文件，也支持从 JSON 文件导入或合并日程。
- GitHub 文件同步：填写仓库信息和 GitHub Token 后，可以把日程数据上传到仓库文件，或从仓库文件拉取数据。
- 深色模式：支持浅色和深色主题切换，并会记住主题偏好。
- 数据统计：显示当日全部日程、已完成和待完成数量。
- 本地保存：数据保存在浏览器 `localStorage` 中，刷新页面后仍会保留。
- 响应式布局：适配桌面端和移动端浏览。

## 本地运行

可以直接双击打开 `index.html` 使用。

如果希望通过本地服务预览，可以在项目目录运行：

```powershell
python -m http.server 5173
```

然后在浏览器访问：

```text
http://localhost:5173/
```

## 数据说明

当前项目使用浏览器本地存储保存日程数据：

```js
localStorage.setItem(STORAGE_KEY, JSON.stringify(schedules));
```

这意味着日程数据默认只保存在当前电脑的当前浏览器里。页面内的 GitHub 文件同步功能可以把数据手动上传到仓库中的 JSON 文件，但需要你提供具备仓库写入权限的 GitHub Token。

## GitHub 数据同步

页面中的 GitHub 同步不会把 Token 写入代码文件。Token 只在当前页面会话中使用，仓库 Owner、仓库名、分支和数据文件路径会保存在浏览器本地，方便下次填写。

推荐的数据文件路径：

```text
dailyplanner-data.json
```

使用步骤：

1. 在 GitHub 生成一个具备当前仓库内容读写权限的 Token。
2. 在页面的“GitHub 数据同步”区域填写 Owner、仓库名、分支、数据文件路径和 Token。
3. 点击“上传到 GitHub”保存当前日程数据。
4. 在其他设备打开页面后，填写同样信息并点击“从 GitHub 拉取”恢复数据。
